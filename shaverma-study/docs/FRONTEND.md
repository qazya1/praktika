# Упрощённый фронтенд

В проекте сохранены базовые элементы интерфейса заведения:

- логотип и брендовая шапка;
- hero-блок;
- категории меню;
- карточки блюд с фотографиями;
- корзина и оформление заказа;
- адаптивный интерфейс;
- аккуратный кабинет сотрудника с фильтрами заказов.

## Картинки товаров

Backend возвращает поле `image_url` в `GET /api/menu`.

Пример:

```json
{
  "id": 1,
  "name": "Классическая шаурма",
  "image_url": "/images/products/classic.svg"
}
```

Поддерживаются:

- локальные пути из `frontend/public`, например `/images/products/classic.svg`;
- полные URL, например `https://cdn.example.ru/menu/classic.webp`;
- относительные backend-пути через `VITE_MEDIA_BASE_URL`.

При ошибке загрузки автоматически показывается `fallback.svg`.

Для замены логотипа достаточно заменить `frontend/public/images/logo.svg`, сохранив имя файла.
