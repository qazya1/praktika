# Публикация в новый GitHub-репозиторий

Рекомендуемое имя: `shaverma-study`.

Через GitHub CLI:

```bash
gh repo create Shira-Artem/shaverma-study --private --source=. --remote=origin --push
```

Через веб-интерфейс GitHub: создайте пустой приватный репозиторий без README, затем выполните:

```bash
git remote add origin https://github.com/Shira-Artem/shaverma-study.git
git push -u origin main
```
